ACCESSORIES DISPLAY BY CONDENSER MODEL
POST /Accessories
================================================

The accessory list is built from remoteModel only.
Temperature is not used.

Items are either:
  - shown and enabled   (IsDisabled = false)  -> user can select
  - shown and disabled  (IsDisabled = true)   -> shown greyed / not selectable
  - not returned        -> not displayed

------------------------------------------------
2. CHECK ORDER
------------------------------------------------

  1) If model ends with -B1 or -B2   -> EC path
  2) Else if model starts with TMC   -> TMC path
  3) Else                            -> standard path (JMK / TMK / TMKQ)

Monophase vs 3-phase uses the last 2 letters of the model:
  MV, MH           = monophase
  DV, DH, YV, YH   = 3-phase
  any other suffix = 3-phase

------------------------------------------------
6. EXAMPLES
------------------------------------------------

 Model example              | Path                         | What the UI shows
----------------------------+------------------------------+------------------------------------------
 ...-B1 or ...-B2           | EC                           | W1E, W3E, Eb, Ep, switch, shock,
                            |                              | corrosion; painting greyed
 TMC...                     | TMC                          | Wiring + switches + mechanical;
                            |                              | all speed controllers greyed
 JMK...DV  (3-phase)        | Standard 3-phase             | R and P controllers on;
                            |                              | G, Z and monophase controllers off
 TMKQ...                    | Standard TMKQ 3-phase        | R, P, G, Z on; monophase controllers off
 ...MV  (1 fan row)         | Monophase                    | Monophase controller R (id 8) on;
                            |                              | ids 3-7 off
 ...MV  (2 fan rows)        | Monophase                    | Id 8 also off


------------------------------------------------
7. NOTES
------------------------------------------------

- POST /Accessories request body: id, remoteModel only.
- POST /AccessoriesPrices prices selected item IDs; it does not rebuild
  this display list by temperature.
- Min operative temperature is not applied. There is no operating-
  temperature column on accessory items.
- Source: ThermokeyCondensers.vb  AccessoriesItemList
