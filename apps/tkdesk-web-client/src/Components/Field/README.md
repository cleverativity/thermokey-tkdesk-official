# Field

Componenti utilizzati per l'input utente collegati al `Formik` con label annessa.

## FieldCheckbox.tsx

Checkbox semplice

## FieldInput

Campo di input testo e/o numerico

## FieldRangeSelect

Semplice select che riceve in input delle opzioni

## FieldDecimalNumber

Un input specifico per i numeri, permette di modificare il numero di decimali e aggiungere un prefisso (es: unità di misura), vedere `InputNumber` di `antd` per le varie possibilità
