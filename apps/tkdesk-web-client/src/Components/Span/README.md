# Span

Potenziamenti del semplice `<span></span>` di html.

## Span.tsx

Componente semplice alcune `props` utili come la funzione per trasformare il valore e l'onClick.

## SpanIntl.tsx

Componente base che tramite un `prefix` e un `value` localizza la stringa risultato di `prefix+value`

## SpanLinkButton.tsx

Icona di link utilizzabile come pulsante inline per i vari `Span*.tsx`
