# Generic

La cartella `Generic` raccoglie delle unita' di funzionalita' generiche, che vengono spesso implementate e che quindi meritano di essere astratte, e in qualche modo riutilizzate, per ridurre la duplicazione del codice.

I moduli generici possono essere visti come dei generatori di codice, o come delle implementazioni incomplete, che necessitano di una serie di dati per essere specializzate e divenire pronte all uso.

Molto spesso sono funzioni che accettano dei parametri di configurazione e poi restituiscono l'oggetto specializzato, o dei componenti React con molti parametri.

Tipicamente quindi questi moduli non vengono usati direttamente, perche' molto astratti, ma servono per greare degli oggetti, a cui viene dato un nome e che poi vengono utilizzati nell'applicazione.
